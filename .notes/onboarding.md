Onboarding that teaches by doing (no tours)

Document-first onboarding (local, no account):

Open into a real doc titled “Start Writing.” The body is the tutorial.

First line hints: “Press ⌘K and try: line length 66ch · focus on · insert equation”.

As they complete actions, subtle checkmarks appear in the margin (no popups).

Ghost suggestions only on idle (e.g., after 8s): “Try export pdf”.

A footer chip “Everything is saved locally” + “Enable backups?” (optional).

All progress + prefs in IndexedDB (Dexie); no telemetry unless they opt in.

A single help command opens a searchable cheatsheet (and can run examples inline).
